Test configuration

Profiles.

A profile is an independent test plan: its own schedule (interval or cron), its own server strategy (automatic, one fixed server, rotate through a list, or test every server in a list each run), and optional network interface / source IP binding. Tests from all profiles run one at a time through a shared queue so they never skew each other.
